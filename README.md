# Learning Management System (LMS)

A full-stack Learning Management System built using Spring Boot, Spring Security, Thymeleaf, PostgreSQL, and Tailwind CSS.

## Features

### Authentication & Authorization
- User Registration and Login
- Role-Based Access Control
- Forgot Password & Reset Password
- Secure Password Encryption using BCrypt

### Student Features
- Browse Available Courses
- View Course Lessons
- Watch Video Lessons
- Download Learning PDFs
- Track Learning Progress

### Instructor Features
- Create Courses
- Add Lessons
- Upload Learning Materials
- Manage Course Content

### Admin Features
- Manage Users
- Manage Courses
- Monitor Platform Activities
- Role-Based Dashboard Access

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate

### Frontend
- Thymeleaf
- Tailwind CSS
- HTML5
- JavaScript

### Database
- PostgreSQL
